\# Wire's Notification Overhaul

===

\## Features:

* Stacked left-side notifications with icons. Identical notifications merge instead of duplicating.
* Valheim's large center-screen notifications are moved into the same left notification stack
* Potion/mead effects show a notification when their consumed status effect naturally ends.
* Optional skill XP-gain notifications; Optional required XP progress display
* Optional pickup-notifications-only mode.
* Optional Compact Mode
* Configurable duration, maximum visible notifications, panel position, font size and text color.
* Configuration can be server-synced and locked by server admins.
* Direct support for FortifySkillsRedux
