# Wire's Legacy Raids

Brings old progression raids back later in the game for more variety and another way to gather earlier materials.

At every normal Valheim raid check, vanilla gets its normal roll first. If it does not start a raid, Legacy Raids gets a separate **10%** chance by default to start one of the progression raids that your world has already retired.

The old raids are chosen evenly from the eligible pool, so the pool naturally gets more varied as you progress. Existing evergreen raids such as trolls and gjalls remain part of Valheim's normal system.

Legacy raids use the original vanilla event: same enemies, duration, messages, drops, biome restrictions, base requirements, and unlock conditions. Only a boss-defeat progression cutoff that retired the raid is ignored.

The bonus chance is configurable.

## Multiplayer

The mod needs to run on the host/server that controls raids. Other players do not need it installed because the selected raids are normal vanilla events.
