# Changelog

## 0.1.0

- Added a separate bonus raid roll after normal Valheim raid checks that do not start an event.
- Default bonus chance is 10% per raid roll.
- Retired boss-progression raids become eligible again after their normal progression cutoff.
- Legacy raids are selected evenly and keep their original enemies, duration, messages, drops, biome, base, and unlock requirements.
- Only the boss-defeat condition that previously retired a raid is bypassed.
