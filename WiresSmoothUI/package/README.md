# Wire's Smooth UI

Valheim UX but smooth and awesome.

Features:
- Completely overhauled/Completely new inventory, menu and interaction UI animations (see gif on Hexium or Nexus for example)
- Immersive/Dynamic HUD, whatever you'd wanna call it
- Activator key can be held or toggled with keyboard or controller to show the full HUD.
- Controller hotbar navigation reveals the bar while changing selection, with a one-second hold after the last step.
- Smooth inventory, drag, button, tooltip, build-menu and map-pin animations.

Default activator key:
- Keyboard: Backquote / tilde key (left of 1).
- Controller: Select/Create, separately configurable.

Explicitly compatible with:
- Azu Extended Player Inventory 
- My Little UI.
