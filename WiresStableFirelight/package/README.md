# Wire's Stable Firelight

A VERY tiny Valheim mod that makes stationary fire lighting much less visually jumpy.

- Reduces the positional movement of `LightFlicker` on fuel-burning fireplaces by **90% by default**.
- Changing the config needs logging out of the world and logging back in to apply
- One config option: **Light movement reduction**, adjustable from **0% to 100%**.
  - 0% = vanilla positional movement. wiiggle wiiggle wiiggleeee oooo
  - 90% = default.
  - 100% = completely stationary light position.
