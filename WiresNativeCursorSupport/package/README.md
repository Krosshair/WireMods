Replaces Valheim's little eyedropper/sword cursor thing with whatever your OS uses. Fully dynamic and changes the cursor icon depending on the interaction, supports Windows, MacOS and Linux. (Latter 2 are untested since I only have my Windows PC, so if you're using Mac or Linux I'd love to know if it ACTUALLY works lol.)



Toggleable in the accessibility tab in the settings menu.



This mod is NOT a .png replacer like the mod I used last year to just change the valheim cursor png with my own cursor, it actually uses your operating system's cursor.

Hovering over an item will change it to the hand cursor icon, little hourglass while crafting or loading, etc. Again, the exact way it looks is completely dependant on your system and what you use.
