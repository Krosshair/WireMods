# Wire's Grass Tweaks

Modern Valheim grass controls inspired by aedenthorn's Grass Tweaks. (Not a fork)

Presets:

* Default: vanilla values.
* Enhanced: Amount 0.5, Distance 200, Grass Patch Size 12. (Aedenthorn's grass tweaks preset from the comments of that Nexus page)
* Ultra: Amount 1.0, Distance 200, Grass Patch Size 12. (That comment's preset but no downside)



Full settings:
UseLod, UseXZLodDistance, LodMinDistanceMult, LodMaxDistanceMult,
ScaleMinMult, ScaleMaxMult, AmountMult, ClutterDistance,
GrassPatchSize, PlayerPushFade and ShadowCastingMode.

Client-side only.
Built for Valheim 1.0.12.
