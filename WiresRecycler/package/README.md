# Wire's Recycler

Adds a RECYCLE tab to appropriate crafting stations.

* Recycles the exact selected inventory item's base crafting cost. upgrades are never refunded.
* Q1 base recovery: 80%.
* Q2 base recovery: 85%.
* Q3 base recovery: 90%.
* Q4+ base recovery: 100%, capped by the item's natural vanilla quality.
* Potential levels never increase recycling returns.
* Recycling creates crafting-XP debt for the recipe's crafting skill: each recycled craft batch cancels XP from one later craft batch, and multi-craft can pay multiple debt at once.
