# Wire's Acoustics 0.7.0 - world loop lifecycle fades
Date: 2026-11-22
Status: REVERTED from the 0.7.0 release candidate on 2026-11-22. The user reported no audible fade; the feature, lifecycle hooks, and detached tails were removed. This file is historical only.

## Behavior
- Continuous positional fire/station/machine audio starts with a 0.30 second linear-amplitude fade-in.
- Turning a machine off, smelter becoming idle, or a fire running out begins a 0.55 second fade-out at that stop event. Original game object/audio source stops normally; a detached source plays the remainder of the same loop at its world position for 0.55 seconds.
- If the source restarts while its old tail is fading, they overlap naturally; no forced silence gap.
- Loop-tail source resumes from original clip's timeSamples if available. If Unity has already reset playback position, a new random phase is chosen.
- Source output mixer, volume, pitch, 3D attenuation, reverb mix and approximate DSP low-pass are carried to the detached tail. Tail reverts to Unity native panning for the short release, rather than live WA HRTF tracking.
- Break/placement are one-shot audio and unaffected. WearNTear.Destroy marks all source filters in the destroyed piece to avoid lingering tails on demolition/breakage.
- Ambient beds, menu, voice chat, and non-positional sounds excluded. Windmill's native wind-driven smooth volume modulation remains intact; its audible startup is faded if filter can process it.
- On shutdown or when the mod is disabled, all filters are released without spawning tails.

## Implementation
- src/Filter.cs: attack gain in existing OnAudioFilterRead (no new game frame callbacks), release gain in detached LoopReleaseEnvelope.OnAudioFilterRead, Unity Object.Destroy(go, 0.67s).
- src/Starts.cs: natural start on ZSFX.Play (normal or deferred); stop on ZSFX.Stop; shutdown/toggle on ZSFX.OnDisable Prefix before original engine stops source.
- src/Filter.cs: OnDisable/OnDestroy backup release for plain AudioSources or other shutdown events, guarded to run only once per loop.
- src/GeometryEvents.cs: WearNTear.Destroy Prefix disables tails on broken pieces.
- src/Budget.cs: existing Note and 250 ms cleanup track active and stopped loop fade state, no additional Update, LateUpdate, FixedUpdate, coroutine, or polling.
- Existing individual random loop phases, independent-source concurrency patch, relative fire loudness and HRTF algorithm are unchanged.
