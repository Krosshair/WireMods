# Wire's Pings

Ping what you are looking at without opening the map.

Press **G** by default while playing. Wire's Pings raycasts through the centre crosshair and sends Valheim's normal map ping at the hit position.

The hotkey and maximum distance are configurable.

## Multiplayer

Wire's Pings is client-side. It calls Valheim's existing `Chat.SendPing` path, so other players receive the same vanilla ping they would receive from a middle-click on the map. They do not need the mod installed.
