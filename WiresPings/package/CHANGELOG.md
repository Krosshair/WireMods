# Changelog

## 0.1.2
- Rapid aimed pings now immediately retarget the existing local vanilla ping instead of waiting for the previous ping to expire.
- Still sends the normal vanilla ping RPC, so multiplayer recipients continue to receive ordinary Valheim pings.

## 0.1.1
- Changed the default ping hotkey from G to B.
- Increased the default maximum ping distance from 500 m to 1000 m.

## 0.1.0
- Added aimed world pings using Valheim's existing vanilla ping system.
- Press G by default to ping the exact world position under the centre crosshair.
- Other players do not need the mod; they receive an ordinary vanilla ping.
