# Wire's Stand Swap

**Shift + E** anywhere on an armor stand swaps its **entire displayed loadout in one action**. Armor, helmets, legs, capes, utilities, trinkets, weapons, shields and tools all participate. Empty stand slots stay empty.

* Armor pieces exchange with your corresponding worn armor/equipment slot (including **Equipment and Quick Slots**). Weapons and tools exchange with matching worn gear first, then the last-used compatible kind, then a related kind/inventory fallback. Shields only match shields; unrelated gear is never substituted.
* Item stands their displayed item via matching recently used or compatible equipped/inventory equipment.
