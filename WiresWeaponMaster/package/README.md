A visual weapon holster overhaul that displays your recently used weapons and tools across Valheim’s existing holster positions. Fully client-side.

==
Custom keybind, kinda: hold R for about a second (or whatever you have weapon stowing set to) to reset your equipment history to clear it.
Similarly also works on controller.

Multiplayer: other players using Weapon Master 0.2.0+ can see your extra holstered weapons and tools, and you can see theirs. No server install required.



The different weapon holster categories (vanilla thing) (no 2 times in the same category can be shown at the same time, latest replaces old:

* backShield, shields and dual axes
* backTool - Hip slot! hammer, knives, small stuff
* backMelee - swords, maces, etc
* backTwohandedMelee - Two handed melee, and spears for some reason
* backAtgeir - Mainly Atgeirs haven't seen anything else there
* backBow - Bows, Crossbows etc



These categories are made by the devs of Valheim and do not literally represent which items are shown in that category. Except atgeirs, those are their own specific thing i guess lol. One of these categories is the hip hammer/knife/summoning skull/small stuff slot, not sure which exactly, but dw those are shown too. On the nexusmods and hexium pages of this mod you can see images with multiple examples of this mod in action.
